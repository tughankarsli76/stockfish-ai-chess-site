Choose an engine

Open Options → Change Engine. Stockfish 19, Reckless 0.9.0, PlentyChess 8.0.0, Pawnocchio 2.0.1, Obsidian 16.0, Cinder 0.6.1, Viridithas 20.0.0, Halogen 16.0.0, Clover 9.1, and Starzix 6.1 are included. All work without an internet connection.

Engine matches

Open Game → New Game → Engine Match. Choose each engine and time per move or time per game. Use the Game menu to pause, resume, or stop. Opening menus pauses a match.

Analysis and strength

Stockfish 19 supports adjustable playing strength. Other engines play at full strength. Pawnocchio, Cinder, Viridithas and Starzix display one analysis line; the other included engines support multiple lines. WDL percentages appear only when supported by the engine or opening data.

Save and transfer games

Use Game → Save Game or Export Game. PGN files can be imported through the iOS document picker. Public-game imports from Chess.com and Lichess require internet access and an existing public username.

Screen and background play

The screen stays awake during a live game. Locking the screen pauses play and saves your position; engine matches stay paused until you select Resume Match. When you switch apps, the current engine search can continue for as long as iOS grants background time, and its latest result appears when you return. Engine matches can keep playing in the background when iOS grants execution time; cancellation or expiration pauses the match and saves its progress. Force-closing the app stops background work.

Sounds and haptics

Options → Sound controls move and capture sounds. Options → Haptics controls move feedback on supported devices.

Device benchmark

Options → Stockfish Chess Benchmark runs a 15-second search and reports positions per second and Relative Speed. Use Run Again to repeat it.

Warm device or battery use

Long analysis uses the processor. Select one thread and a shorter analysis time in Options, or stop analysis when finished. Longer searches use more battery.

Board appearance

Options → Board includes Honey Wood and other colors. Change the chess pieces separately under Options → Pieces.

Independent app

This app is independently developed and is not an official Stockfish, Chess.com, or Lichess app.
